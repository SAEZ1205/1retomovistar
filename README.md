# MOVISTAR Reto 1 — LucIA · Checkpoint 20

Versión autosuficiente reconstruida del último checkpoint trabajado antes de pedir el ZIP final.

## Incluye
- Inicio estilo Mi Movistar.
- Recibo actual + cinco anteriores.
- Gráfica histórica y fichas de cada mes.
- Pantalla **Entiende tu recibo**.
- Comparación julio S/59.90 vs agosto S/62.40.
- Explicación de prorrateo + tres hitos fechados.
- Modal **¿Cómo llegamos a esta explicación?** con trazabilidad y acceso a fichas.
- Sección **Conoce tu recibo técnicamente** con 10 conceptos desplegables.
- Varias poses de LucIA reconstruidas como SVG locales.
- Chat flotante, feedback, siguientes acciones y derivación simulada a asesor.
- Vista de Call Center simulada.
- Diseño responsive para celular y laptop.

## Ejecutar
1. Descomprime el ZIP.
2. Abre una terminal dentro de la carpeta.
3. Ejecuta `npm install` (no instala dependencias externas; solo deja preparado npm).
4. Ejecuta `npm run dev`.
5. Abre `http://localhost:3000`.

También puedes abrir `index.html` directamente; la mayor parte funciona sin servidor.

## Nota de preservación
Este paquete no depende de `node_modules`, ni incluye `.git`. Guarda este ZIP como respaldo independiente.
